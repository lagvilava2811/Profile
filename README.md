# ვაკო ლაგვილავა | ციფრული სააგენტო & Portfolio

ხელნაკეთი 3D ინტერაქტიული პორტფოლიო და ციფრული სააგენტოს ვებსაიტი.

## 🚀 მახასიათებლები (Features)

- **ინტერაქტიული 3D გამოცდილება**: Three.js & Canvas-ზე აგებული ხელნაკეთი 3D ესთეტიკა
- **სერვისები**: ვებ დეველოპმენტი, UI/UX დიზაინი, AI ავტომატიზაცია, ვიდეო პროდუქცია, SEO
- **ინტერაქტიული კომპონენტები**: მაგნიტური ღილაკები, მორგებული აუდიო ფლეიერი, ხმოვანი ეფექტები, AI დემო
- **გვერდები**:
  - `index.html` — მთავარი გვერდი 3D სამყაროთი
  - `about.html` — ჩვენ შესახებ
  - `services.html` — სერვისების დეტალური ჩამონათვალი
  - `work.html` — ნამუშევრების პორტფოლიო
  - `contact.html` — კონტაქტი და ფორმა

## 🛠 ტექნოლოგიები (Tech Stack)

- **HTML5 & CSS3** (Custom Animations, Layouts, Responsive Design)
- **Modern JavaScript (ES6+)**
- **Three.js** (3D Rendering & Animation)
